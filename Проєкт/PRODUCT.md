# Навчальні UX-прототипи

## Platform
web

## Stack
Статичні HTML/CSS/JavaScript для відтворюваної демонстрації; Figma Plugin API для редагованих макетів. Вибір реалізації в межах лабораторних завдань.

## Users
Згідно з індивідуальними завданнями: студенти академічного обміну; нові жителі міста; люди, що вивчають мови; користувачі нагадувань про ліки.

## Product Purpose
Виконати навчальний цикл аналізу, моделювання, прототипування та оцінювання інтерфейсів.

## Capabilities and Constraints
Варіант 19; індивідуальні підзавдання №5. ЛР5 містить 15 наскрізних варіантів: використовується №5. Макети медичних нагадувань містять лише демонстраційні дані, не призначення чи поради щодо лікування.

## Evidence on Hand
Методичні вказівки і лекції. Реальні відповіді опитування та записи учасників поки не надані. Персони до збору відповідей — гіпотези.

## Accessibility & Inclusion
WCAG 2.1 AA, клавіатурне керування, видимий фокус, підписи, контраст, цілі керування від 44 px.
