# UX-дослідження академічного обміну

Мета: зрозуміти пошук програм обміну, перевірку вимог та підготовку документів. Добровільно, 5–7 хвилин, без імені, пошти та документів. Можна припинити в будь-який момент. Не вводьте персональні або медичні дані.

1. Чи погоджуєтесь на анонімне використання відповідей у навчальному UX-дослідженні? Так / Ні (Ні → завершення).
2. Ваша ситуація: планую виїзний обмін / уже брав(-ла) участь / навчаюсь в Україні як іноземний студент / інше.
3. Який пристрій найчастіше використовуєте для пошуку програм? Смартфон / ноутбук / інший.
4. Згадайте останній пошук програми. З чого почали? Відкрита відповідь.
5. Яку інформацію найважче знайти? Дедлайн / мову / фінансування / документи / контакти / інше (множинний вибір).
6. Як відстежуєте готовність документів і терміни? Відкрита відповідь.
7. Що змусило б відмовитись від подачі? Відкрита відповідь.
8. Яку одну функцію хотіли б мати передусім? Відкрита відповідь.

## Інтерв’ю (7 хвилин)
Після окремої згоди попросіть згадати конкретний випадок, показати послідовність без приватних документів, пояснити останню перешкоду, спосіб її подолання та критерій довіри до вимог. Не підказуйте бажану відповідь. Фіксуйте код P01…P05, спостереження та дослівну цитату окремо від інтерпретації.

## Affinity mapping
Кожна нотатка має ID джерела. Кластери: цілі; дедлайни; документи; фінансування; мовна доступність. Патерн вважається повторюваним лише за підтримки двох різних учасників. Персони уточнюються після п’яти анкет та одного інтерв’ю.
